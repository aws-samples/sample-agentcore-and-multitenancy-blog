# Tech Stack & Build

## Language & Runtime

- Python 3.12+ (deployed via AgentCore `direct_code_deploy` or Docker container)
- AWS region: `us-east-1`

## Core Frameworks & Libraries

- **Amazon Bedrock AgentCore** (`bedrock-agentcore`, `bedrock-agentcore-starter-toolkit`) — Serverless agent runtime, memory, gateway
- **Strands Agents** (`strands-agents`, `strands-agents-tools`) — Agent orchestration, tool registration via `@tool` decorator
- **Streamlit** — Web UI (`app.py` entrypoint, runs on port 8501)
- **boto3 / botocore** — AWS SDK for S3, SSM, Bedrock, Cognito, Knowledge Bases
- **OpenTelemetry** — Observability and cost tracking via baggage propagation
- **PyJWT** — JWT decoding for Cognito tokens
- **DuckDuckGo HTML scraping** (premium tier only) — Web search without API keys

## AWS Services Used

- Bedrock AgentCore (Runtime, Memory, Gateway, Policy Engine)
- Bedrock Knowledge Bases (document retrieval with metadata filtering)
- Amazon Cognito (authentication, multi-tenant user pools)
- SSM Parameter Store (configuration at `/app/healthcare/...`)
- S3 (document storage, organized by tier/clinic)
- Lambda (backend API functions)
- API Gateway (REST API with Lambda proxy)
- CloudFormation (infrastructure templates in `prerequisite/`)

## Common Commands

```bash
# Setup
python3 -m venv .venv
source .venv/bin/activate
pip install -r dev-requirements.txt

# Full deployment (infra + agents)
chmod +x deploy.sh
./deploy.sh

# Run web UI
streamlit run app.py --server.port 8501

# Run tests
pytest test/

# Cleanup all resources
chmod +x scripts/cleanup.sh
./scripts/cleanup.sh
```

## Configuration

- SSM parameters live under `/app/healthcare/` namespace
- Deployment config: `config/deployment_config.json`
- AgentCore config: `.bedrock_agentcore.yaml` (auto-generated by `agentcore configure`)
- Infrastructure templates: `prerequisite/*.yaml`
- Tier selection: `AGENT_TIER` environment variable (`basic` or `premium`)
