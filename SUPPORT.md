# Support

## Getting Help

If you need help with this project, here are your options:

### Documentation

- Start with the [README](README.md) for setup and usage instructions
- Review the [Contributing Guide](CONTRIBUTING.md) for development workflows

### Questions and Discussions

- Open a [GitHub Issue](../../issues) for bugs or feature requests
- Use [GitHub Discussions](../../discussions) for general questions and community support

### Reporting Bugs

When reporting a bug, please include:

- Your environment (OS, Python version, AWS region)
- Steps to reproduce the issue
- Expected vs actual behavior
- Relevant logs or error messages

### Security Issues

For security vulnerabilities, please see [SECURITY.md](SECURITY.md) for
responsible disclosure instructions.
